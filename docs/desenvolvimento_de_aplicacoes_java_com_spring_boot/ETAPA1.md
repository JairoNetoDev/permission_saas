
Etapa 1: **Orientação a Objetos Avançada**

**Competência avaliada**

*Desenvolver aplicações Java utilizando conceitos avançados de orientação a objetos.*

**Objetivo**

*Construir o modelo de negócio da aplicação utilizando recursos da orientação a objetos em Java.*

**Feature a ser desenvolvida**

1. **Criação do projeto**Criar um projeto utilizando Java e Spring Boot que será desenvolvido durante toda a disciplina. Nesta primeira etapa, o foco estará na construção e utilização das classes Java que representam o domínio escolhido.
2. **Modelo de negócio**Desenvolver um modelo de negócio contendo pelo menos quatro classes. O modelo deverá apresentar: relacionamento entre objetos; pelo menos um relacionamento do tipo um-para-muitos; utilização de herança, abstração ou interfaces quando fizer sentido para o domínio; responsabilidades adequadamente distribuídas entre as classes. A utilização de herança deverá representar uma relação coerente entre os elementos do domínio, evitando seu uso apenas para atender ao requisito do projeto.
3. **Atributos e comportamentos**As classes deverão possuir atributos e comportamentos compatíveis com o domínio escolhido. Ao longo do modelo deverão existir atributos que representam diferentes tipos de informação, incluindo: texto; números inteiros; números reais; valores lógicos; datas. Cada classe deverá possuir uma representação textual adequada através da implementação do método toString().
4. **Inicialização e teste do modelo**Criar uma rotina de inicialização que instancie objetos, estabeleça os relacionamentos definidos e apresente os dados no console. O objetivo é demonstrar o funcionamento do modelo antes da inclusão das demais camadas da aplicação.

**Marco da Etapa 1**

Ao concluir esta etapa, registrar no repositório a tag: etapa-1. Esse marco será utilizado como evidência para avaliação da primeira competência.
